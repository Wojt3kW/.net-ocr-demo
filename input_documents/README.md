# Dokumenty wejściowe

Wrzuć tutaj skany do porównania: `.pdf`, `.png`, `.jpg`/`.jpeg`, `.tif`/`.tiff` (także wielostronicowe), `.bmp`.

Opcjonalnie dodaj wzorzec tekstu do policzenia jakości (CER/WER):
`faktura.pdf` → `faktura.gt.txt` (UTF-8, cały tekst dokumentu; podział na linie nie ma znaczenia,
liczy się kolejność słów – tabele najlepiej wiersz po wierszu).

Zawartość katalogu (poza tym plikiem) jest ignorowana przez git.
